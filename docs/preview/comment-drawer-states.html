⑥ 尾行会不会被评论输入框遮挡？不会（已核实）

抽屉是 display:flex;flex-direction:column：.acsv-drawer-list 为 flex:1;overflow-y:auto（滚动区），输入栏 .acsv-cinput{flex:none} 是**挂在抽屉上的 flex 兄弟节点、在正常流里**（comments.js 挂 h.el）——不是覆盖层。 ⇒ 列表可滚区域**正好止于输入栏上沿**，尾行滚到底就停在输入栏上方（左图虚线=边界）。 唯一会盖住列表底部的是表情面板（.acsv-emotpanel{position:absolute;bottom:57px}，右图）—— 这是**既有行为**（今天最后几条评论同样被盖），且只在"正在选表情"时临时出现，选完/Esc 即收。
