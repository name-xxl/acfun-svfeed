规则小结（待确认后落地到 pickpop.place）
  • 时机：内容到达后重算一次（首屏渲染完 + 层内新建刷新后都重跑）；尺寸变化由 ResizeObserver 兜底。
  • 垂直：优先向下（锚点下缘 + 6px）；下方可用空间 < 240px 且上方更宽裕 → 翻到锚点上方（底边 = 锚点上缘 − 6px）； 高度上限 = 所选方向的可用空间（且 ≤ min(420px, 64vh)），列表内部滚动、footer 常驻 → 永不越出视口。
  • 水平：右缘对齐锚点右缘；越界则收进视口并保 8px 内边距（原为左缘对齐 + 4px）。
  • 窄宽 540：宽 260px 的弹层仍贴锚点左展开；垂直规则同上（可用空间更小 → 更常触发翻上/压高）。
