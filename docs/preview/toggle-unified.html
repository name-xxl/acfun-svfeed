④ 需要你裁决的五件事前两条会改变现有观感，后三条只是归并

  • 1悬停提亮：现状两处都没有 hover 态。提案加"轻微提亮"。要不要？不要则删掉这条。
  • 2键盘焦点环：现状没有 focus 样式；统一成 button 后键盘可聚焦，不加环会出现"能聚焦但看不见"。建议加（可访问性最小集，项目已有先例）。
  • 3DOM 形态：统一为 button + <i>（原生页由 span 改 button）。顺带修掉 span 不可聚焦/不可键盘操作。
  • 4过渡时长：.15s（齿轮）与 .2s（原生页）二选一——建议 .15s，原生页会快 50ms。肉眼几乎不可辨。
  • 5旋钮阴影：浅色皮保留（白旋钮压浅底需要），暗色皮保持无阴影。即按皮肤分 token，与现状一致。
