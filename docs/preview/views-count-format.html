播放/计数「万」文案口径统一 —— 静态预览（裁决后进 src 实现）

现状：同一指标存在两套「万」口径——滑卡/精选网格/点赞计数走 ui.fmt（toFixed(1)，出 1.0万）； 面板网格卡/行卡/粉丝数走 timefmt.fmtWan（整数半进位，出 1万）。
全量复算 [1万, 300万]：两口径显示不同的数字共 30 万个（约 10%）；其中 尾随 .0 样式差 298,804 例（如 10000 → 1.0万 vs 1万）， 真值分岔仅 1,196 例（全是 x.x5 半值：11500 → 1.1万 vs 1.2万，浮点 vs 半进位）。
本稿只决定「文案口径」，无版式与交互形态变化；文末勾选方案 A / B / C。
