FEATURES

功能一览

从竖刷播放到左栏视图，一套脚本覆盖 A 站 PC 端的竖版消费场景。

▶

竖滑播放

滚轮/方向键/JK 翻页带吸附；点击开声、悬停浮出控制栏；进度拖带缩略图；三级全屏；0.5–3.0 倍速记忆。

‼

双源信息流

顶栏「小视频｜推荐」切换：meow 竖版短视频 与 APP 单列精选流；地址栏即分享链接，刷新/粘贴可回跳。

弹

弹幕与推荐模式

推荐源对齐 APP：高级弹幕、清晰度 360P–1080P60 切换保进度、发弹幕、投蕉收藏。

✉

评论与私信抽屉

嵌套评论自动续页、划选复制、发评配表情图；私信聊天支持作品卡/引用/图片；两抽屉互斥避让画面。

▦

左栏视图

榜单/分区/关注/广场/我的/搜索同一套壳内切换；卡片点进就地播放，Esc 逐层返回。

✚

官方页面增强

个人中心动态广场、空间页小视频/动态标签、原生页评论 IP 与设备标签——总开关管理，可全关。

INSTALL

三步装上

浏览器安装 Tampermonkey 扩展（tampermonkey.net）。
打开 最新版 acfun-svfeed.user.js，Tampermonkey 会自动弹出安装页，确认即可。
打开 A 站首页，顶部导航出现「小视频」项，点进去开始竖刷。
